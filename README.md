# ロマ子アクション 〜王冠とうんこの伝説〜

ブラウザで遊べる、ファミコン風の横スクロールアクションゲームです。
HTMLファイル1つだけでできています（インストール不要・通信なし）。

## ▶ 遊ぶ

**https://ユーザー名.github.io/romako-action/**

（↑ 公開したら、自分のURLに書きかえてください）

## 遊びかた

| したいこと | パソコン | スマホ |
|---|---|---|
| 移動 | ← → キー | 画面下の ◀ ▶ |
| ジャンプ | スペース / ↑ | 「ジャンプ」ボタン |
| うんこを投げる | X / Shift | 「💩なげる」ボタン |

- **ロマ子様**（青髪）が主人公。やられると**ヤミ子**（赤髪）が交代で出撃します
- **👑 王冠**：ピンクの ♛ ブロックを下から叩くと出現。取ると 💩 が投げられるようになり、当たった敵は退場します
- **❤ 赤いヘアピン**：赤い ♥ ブロックから出てくる 1UP アイテム。残機が1つ増えます
- **敵**：二足歩行のオオカミ／カメラを持ったキモオタ（赤く狙いをつけてからフラッシュを浴びせてきます）
- 敵は踏んでも倒せます
- 全2ステージ。ステージ1をクリアすると、雲の上のステージ2に自動で続きます

## 技術的なこと

- HTML + JavaScript + Canvas 2D のみ。ライブラリ・ビルド・サーバー不要
- キャラクターや背景はすべてコード内でドット絵として描画しています
- 外部への通信は一切ありません
